# W2-PM4 — theHarvester Footprinting

**Target:** `networkwalks.com`  
**Status:** In progress

## Objective
Use theHarvester for passive information gathering and document the selected data source, command, and returned results.

## Evidence layout
- `results/` — saved command output.
- `screenshots/` — screenshots of the tool invocation and results.

## Reporting
Record the tool version, data source, exact command, results, and limitations. Distinguish information returned by a public source from information independently verified. Do not add results that were not observed.
