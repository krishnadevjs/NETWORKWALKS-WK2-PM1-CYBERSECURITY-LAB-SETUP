# W2-PM1 — Footprinting with Multiple Tools

**Target:** `networkwalks.com`  
**Status:** In progress

## Objective
Perform basic footprinting and technology identification using multiple command-line tools, then document the observations with supporting output and screenshots.

## Tools
1. WHOIS
2. DIG
3. HOST
4. NSLOOKUP
5. WhatWeb
6. theHarvester

## Evidence layout
- `results/` — captured command output (for example, `.txt` files).
- `screenshots/` — screenshots showing the relevant command and result.

## Reporting
For each tool, record:
- Purpose of the tool
- Exact command used
- Key output observed
- Interpretation and limitations
- Corresponding screenshot filename

Do not infer vulnerabilities from DNS records or technology fingerprints alone. Include only results that were actually obtained during the practical.
